GITHUB + STREAMLIT DEPLOYMENT GUIDE

1. Create a new GitHub repository, e.g. healthcare-fraud-phd-demo.
2. Extract this ZIP.
3. Upload these files to the repository root:
   - streamlit_app.py
   - requirements.txt
   - README.md
   - .gitignore
4. Commit the files.
5. Open Streamlit Community Cloud.
6. Sign in/connect GitHub.
7. Click Create app.
8. Choose your repository and branch.
9. Entrypoint file: streamlit_app.py
10. Click Deploy.
11. After deployment, copy the streamlit.app URL for your panel presentation.

LOCAL TEST:
pip install -r requirements.txt
streamlit run streamlit_app.py

PANEL ORDER:
Executive Dashboard → Research Workflow → Fraud Risk Analyzer → Explainability →
Blockchain Evidence → Published Results → Viva Mode

IMPORTANT:
The bundled web demo uses synthetic data so it can run reliably.
Published study results are shown on a separate page.
For exact reproduction, integrate the original research datasets and exact saved model pipeline.
