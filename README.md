# Blockchain-Based Framework for Healthcare Insurance Fraud Prevention

Academic Streamlit prototype for doctoral research demonstration.

## Sections
- Research Overview
- Dataset Profile
- Methodology
- Provider Risk Analysis
- Explainability
- Blockchain Verification
- Experimental Results
- Research Objectives

## Run
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

The interactive interface uses a lightweight demonstration dataset for stable deployment. Published dataset statistics and experimental results are displayed separately.
