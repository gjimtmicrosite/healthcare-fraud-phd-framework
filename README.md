# Healthcare Insurance Fraud Detection and Blockchain Evidence Framework

Research implementation workbench for doctoral demonstration.

The application is organized as an implementation environment rather than a presentation dashboard.

## Sections
1. Project Overview
2. Dataset and Integration
3. Preprocessing
4. Model Training
5. Evaluation
6. Explainability
7. Blockchain Evidence
8. Reproducibility Record

## Run locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deployment
Use Streamlit Community Cloud and set the entrypoint to `streamlit_app.py`.

## Important research note
The workbench supports a live demonstration dataset or an uploaded provider-level CSV. Published benchmark values are displayed separately. Exact reproduction of the published experiment requires the exact original datasets, preprocessing pipeline, validation scheme, and environment.
