HOW TO REPLACE THE CURRENT VERSION

1. Open the existing GitHub repository:
   healthcare-fraud-phd-framework

2. Replace:
   streamlit_app.py
   requirements.txt
   README.md

3. Commit to main.

4. Streamlit will normally redeploy automatically.
   If required, open Manage app and reboot.
